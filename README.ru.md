# xpayment — плагин xPayment для Claude, Codex и ChatGPT

[English](README.md) · Русский

Принимайте оплату через Kaspi Pay с помощью своего AI-ассистента. Плагин ведёт вас от нуля до первого настоящего платежа: входит в ваш аккаунт [xPayment](https://xpayment.kz), готовит кассу, прогоняет полный цикл в песочнице, пишет код интеграции или публикует платёжную страницу, настраивает вебхук и переводит всё на бой. В плагине только текст и настройки: четыре навыка (инструкции для AI) и адреса двух MCP-серверов. Скриптов и хуков в нём нет.

## Безопасность

- **Вы входите через xPayment.** Вход идёт на странице самого xPayment, «Войти через xPayment». Затем страница согласия показывает права, которые просит AI, и вы разрешаете их или отказываете.
- **Опасные действия — только после вашего «да» в чате.** Удаление кассы, отзыв ключа, удаление подписки на вебхуки или смена её секрета, архивирование и публикация платёжной страницы, возврат по настоящему платежу, касса сверх тарифа: AI делает это, только когда вы ответили «да» именно на это действие. Общее «делай всё» не считается.
- **Боевые ключи и секреты вебхуков не попадают в чат.** AI даёт одноразовую ссылку (она действует час): вы открываете её, один раз видите значение и сохраняете его сами, например в `.env`. Если вы всё же отправили ключ в чат, AI скажет заменить его.
- **Сначала тест.** Весь цикл проходит в песочнице на тестовых ключах (`xapi_test_…`): без денег и без Kaspi. Настоящий платёж AI создать не может, а менять боевые объекты начинает, только когда вы попросили именно бой.
- **Вы видите, что делал AI, и можете это остановить.** Журнал действий и отзыв доступа — в кабинете: «Настройки → Подключённые AI».
- **Ваши данные уходят в тот AI-сервис, который вы выбрали.** Всё, что AI читает в вашем аккаунте, включая телефоны и email плательщиков, отправляется в этот сервис (Claude, ChatGPT или Codex).

## Установка

Плагин называется `xpayment` и лежит в этом репозитории. Ниже — коротко; все шаги с точными названиями кнопок — в [docs/platforms.md](docs/platforms.md) (на английском).

- **Claude Code** (2.1.319 или новее):

  ```sh
  claude plugin marketplace add xpayment-kz/xpayment-ai
  claude plugin install xpayment@xpayment
  ```

  Затем войдите в аккаунт: `/mcp` → `plugin:xpayment:xpayment` → Authenticate.
- **Claude (claude.ai, приложение для компьютера, Cowork):** Персонализация → Плагины → «+ Добавить» → «Добавить маркетплейс» → «Добавить из репозитория» → введите `xpayment-kz/xpayment-ai` → «Синхронизация» → карточка «xPayment» → «Добавить». Потом в плагине подключите оба коннектора (Коннекторы → «Подключить») и войдите в `xpayment` через «Войти через xPayment».
- **Claude, только коннектор (без плагина и навыков):** Персонализация → Коннекторы → «+ Добавить» → «Добавить пользовательский коннектор», адреса `https://api.xpayment.kz/mcp/docs` и `https://api.xpayment.kz/mcp`.
- **Codex CLI** (проверено на 0.167.0):

  ```sh
  codex plugin marketplace add xpayment-kz/xpayment-ai
  codex plugin add xpayment@xpayment
  codex mcp login xpayment
  ```

- **ChatGPT в браузере (только инструменты, без навыков):** Плагины → «Добавить» → «Добавить пользовательский сервер MCP»: название `xPayment`, «URL-адрес сервера» `https://api.xpayment.kz/mcp`, аутентификация OAuth; затем войдите через «Войти через xPayment».
- **ChatGPT, приложение для компьютера:** загрузите архив плагина (Плагины → «Добавить» → «Загрузить архив плагина»). chatgpt.com архив принял, но он запускается только в приложении для компьютера, и там он **не проверялся**.

Проверено 2026-11-10. Подробности, что должно появиться и чего ждать на каждой платформе — в [docs/platforms.md](docs/platforms.md).

## Первое сообщение

Когда плагин установлен, напишите ассистенту:

> Подключи приём оплаты через xPayment

Запустится навык `integrate`: он задаёт по одному вопросу и всё делает сам.

## Навыки

| Навык | Что делает |
|---|---|
| `ask` | Отвечает на вопросы об xPayment по актуальной документации и, если вы вошли, по вашему аккаунту. Ничего не меняет. |
| `integrate` | Ведёт от входа до первого боевого платежа: сценарий, аккаунт и касса, полный цикл в песочнице, код или платёжная страница, вебхук и переход на бой. |
| `migrate-v2` | Переносит интеграцию с API v1 на API v2 (бета) за флагом и без простоя; ключи v1 отзывает последними. |
| `check` | Проверяет интеграцию (код и аккаунт) по актуальной документации и сообщает о проблемах по важности, с исправлениями. |

Как вызвать навык:

| Платформа | Вызов |
|---|---|
| Claude Code | `/xpayment:ask`, `/xpayment:integrate`, `/xpayment:migrate-v2`, `/xpayment:check` |
| Claude (claude.ai) | `/integrate` (кнопка «Попробовать в чате» открывает чат с ним); навык также включается, когда запрос ему подходит |
| Codex | навыки в списке называются `xpayment:ask`, `xpayment:check`, `xpayment:integrate`, `xpayment:migrate-v2` |
| ChatGPT | `@xPayment` в чате (у пользовательского MCP-сервера есть инструменты, но нет навыков) |

## Обновление

- **Claude Code:** `claude plugin marketplace update xpayment`, затем `claude plugin update xpayment@xpayment`, потом `/reload-plugins` или новая сессия. Claude Code хранит кэшированную копию, пока не изменится версия плагина.
- **Claude (claude.ai):** Персонализация → Плагины → «+ Добавить» → «Управлять маркетплейсами» → `xpayment-ai` → ⋯ → «Проверить обновления». Автоматическая синхронизация («Синхронизировать автоматически») требует приложения Claude GitHub App.
- **Codex:** `codex plugin marketplace upgrade xpayment`, затем новая сессия.
- **ChatGPT:** загрузите архив новой версии ещё раз; пользовательскому MCP-серверу обновление не нужно.

Если плагин окажется старее, чем требует документация, он сам скажет вам об этом.
